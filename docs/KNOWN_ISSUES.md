## 2026-06-05 — SEO-фиксы Ahrefs: что осталось проверить / хрупкое

Коммит `8f6f9c4` запушен в `main`, Vercel-деплой запущен. На момент закрытия
сессии прод ещё отдавал старый HTML (деплой в очереди сборки) — фикс
применится автоматически по завершении билда (Cloudflare отдаёт HTML как
`DYNAMIC`, кеш чистить не нужно).

**Проверить после деплоя (не подтверждено live):**
- `https://paulburg.com/` в HTML нет `cdn-cgi/l/email-protection` и `mailto:`;
  `sitemap.xml` отдаёт 13 `<loc>`; meta description ≤155 симв.
- **Повторно запустить краул в Ahrefs** — иначе ошибки не пересчитаются.
- «4XX page (2 URLs)»: один URL — `/cdn-cgi/l/email-protection` (закрыт фиксом).
  **Второй URL не подтверждён** — сверить в детализации Ahrefs.

**Хрупкое:**
- Cloudflare **Email Obfuscation остаётся включённым**. Фикс убрал `mailto:` из
  футера, но ЛЮБОЙ новый сырой `mailto:` в HTML снова будет переписан в
  битую `/cdn-cgi/...` ссылку. Email в коде собирать в JS (см. `Footer.tsx`),
  либо выключить Email Obfuscation в дашборде Cloudflare (Scrape Shield).
- `public/apple-icon.png` — 35 КБ (цель была <30 КБ) при корректных 180px.
  Достаточно (с 444 КБ), но можно дожать через pngquant при желании.
- «Slow page (2 URLs)» (главная, mentorship) — метрика зависит от live TTFB и
  тяжёлого inline-CSS/JS (framer-motion). Уменьшены только иконки/картинки;
  если флаг останется после краула — нужна отдельная работа по весу бандла.

## 2026-05-29 — Открытая претензия к дизайну (не решена)

Профессиональный дизайнер охарактеризовал текущий сайт (`main`) как
«похожий на AI-генерацию». Две конкретные, по его словам реальные, проблемы:

1. **Читаемость текста.** Основной питч на hero — мелкий (18px) курсивный
   serif (Newsreader italic) на тёмном фоне; в карточках текст 11–13px;
   моно-лейблы с растянутым трекингом (0.22em). Это объективно тяжело читать.

2. **Повторяемость / «штампованность».** Восемь секций главной построены по
   одному шаблону: eyebrow (моно + золотая риска) + заголовок + подзаголовок,
   одинаковый ритм. Плюс generic-приёмы: `§ NN` маркеры, мигающий курсор,
   координаты места, полая обводка фамилии.

**Статус:** две попытки редизайна (`redesign/v2-editorial-restraint`,
`redesign/v3-refine`) отклонены — см. `docs/DECISIONS.md`. Сайт намеренно
оставлен в исходном виде. Претензия остаётся открытой на будущее.

**Если возвращаться:** не вычитать и не делать мелких незаметных правок
(оба пробовали — пользователь «не увидел разницы»). Нужны либо заметные
шаги с сохранением характера, либо отдельная сильная арт-дирекция; и сначала
показать несколько визуально РАЗНЫХ макетов рядом для выбора.
